## 1. What is Version Control?
*Version Control* is a system that tracks and records changes made to files over time. It allows you to revert back to previous versions, track changes, and work on the same project with others safely.

## 2. What is Git?
**Git** is a free, open-source software installed on your local computer.
## 3. What is GitHub?
**GitHub** is a cloud-based platform that hosts your Git repositories. It lets you store your work on the internet so you can share it and collaborate with developers worldwide.

## 4. What is Git Bash?
**Git Bash** is a command-line interface primarily for Windows. 

## 5. What are the Parts of GitHub?
Here are the main components of GitHub:
 **Repository (Repo):** The main project folder containing all your files and revision history.
 **Branch:** An independent workspace to safely test new features without breaking the main code.
 **Commit:** A saved snapshot or checkpoint of your work.
 **Pull Request (PR):** A request to merge changes from your branch into the main project.

## 6. What are the Stages of Git/GitHub?

1. **Working Directory:** The files you are currently editing and working on.
2. **Staging Area:** A temporary holding space where you prepare the files you want to save.
3. **Local Repository:** Where changes are permanently saved on your own computer.
4. **Remote Repository:** Where your saved local changes are uploaded to GitHub on the internet.
